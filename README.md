# WeatherWise


A Python Flask web application that provides real-time weather information and intelligent clothing recommendations based on both the current weather and the upcoming forecast.

---

## 🌐 Live Demo

Try the application here:

https://weather-app-project-gcab.onrender.com

---

## Features

- 🌍 Search for weather by city
- 🌡️ Display current temperature, humidity and wind speed
- 👕 Intelligent clothing recommendations
- ☀️ Dynamic day and night themes
- 📅 Uses forecast data to provide more accurate advice
- ⚠️ Error handling for invalid city names
